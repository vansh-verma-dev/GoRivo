
# 🚗 GoRivo
- Live : [GoRivo App ](https://go-rivo.vercel.app/)

**GoRivo** is a ride-booking web application inspired by modern ride-hailing platforms. It connects passengers and drivers through a simple and user-friendly interface.

## ✨ Features

- 🔐 User Authentication
- 👤 Passenger & Driver Roles
- 🚕 Ride Booking
- 💰 Dynamic Fare Calculation
- 📍 Ride Tracking
- 📋 Ride History
- ❌ Ride Cancellation
- 🤝 Driver Ride Acceptance

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **API:** REST API
